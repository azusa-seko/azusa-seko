# こんにちは、セコ　アズサです 👋

COACHTECH でフルスタックWeb開発を学習中のエンジニア志望です。
COACHTECH にて学習終了後、Swiftを学習する予定です。
またLinuCレベル１受験予定。
営業、総務、営業事務、経理の経験を生かし

- ①手帳書くこと
- ②ペットのカエル観察
- ③腕輪念珠作成
- ④文章を書くこと
-全体的にじっくり作ることが好きです。

性格は
かなり真面目で締め切りを守ります。

 大切にしている。」と評されています。
